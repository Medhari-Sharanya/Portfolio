# Medhari Sharanya — Placement Portfolio

A responsive developer portfolio built with HTML, CSS and JavaScript.

## Files

- `index.html` — portfolio structure/content
- `style.css` — responsive dark developer design
- `script.js` — navigation, animations and project modals
- `resume.pdf` — add your resume PDF here

## Before deploying

Replace the placeholder GitHub URLs in `index.html` with your actual repositories/profile.

For the resume button, put your PDF in this folder and name it:

`resume.pdf`

## Deploy on Vercel

1. Create a GitHub repository.
2. Upload `index.html`, `style.css`, `script.js`, `README.md`, and `resume.pdf`.
3. Import the repository into Vercel.
4. Deploy.

No build command is required because this is a static website.
